Descripción: El objetivo general del proyecto es desarrollar una página web y una aplicación de escritorio para optimizar la gestión de pedidos 
de una cafetería que actualmente cuenta con un solo trabajador. La solución permitirá a los clientes consultar el catálogo mediante un código QR y realizar pedidos en línea, 
mientras que el vendedor podrá administrar los productos, organizar y gestionar los pedidos, y emitir recibos mediante una impresora. Para ello, se utilizarán tecnologías de desarrollo web y de escritorio, 
junto con una base de datos para gestionar la información del sistema. Se espera reducir los tiempos de atención, facilitar el trabajo del vendedor, 
mejorar la experiencia de los clientes y adquirir experiencia profesional en el desarrollo de software, con la posibilidad de generar ingresos mediante la implementación de la solución.
